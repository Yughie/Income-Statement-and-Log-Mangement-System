# 🚗 Income Statement & Log Management System – Car Wash Business

## 📘 About the Project
Income Statement & Log Management System is a full-stack web application developed to help car wash businesses manage and track their daily operations, employee logs, and income records more efficiently. Built as part of an academic project, this system automates the process of calculating income based on various service parameters and employee work schedules.

## 🌟 Key Features
## 💰 Income Calculation
Calculates accurate charges based on:

* Vehicle type (e.g., motorcycle, sedan, SUV)

* Vehicle size

* Extra service charges

* Active promos or discounts

* Type of service availed (basic wash, full detail, etc.)
